# 📚 Φιλολογικά Ιδιαίτερα — Διαχείριση Ιδιαιτέρων για Φιλολόγους

Web εφαρμογή με **δημόσια εγγραφή** (email + κωδικός) και αποθήκευση σε **PostgreSQL** (π.χ. Neon).
Δεν χρειάζεται Firebase.

## Ρόλοι
- **Καθηγητής/τρια** — κάνει «Εγγραφή» από την αρχική σελίδα. Βλέπει μόνο τα δικά του δεδομένα:
  μαθητές, ραντεβού (και επαναλαμβανόμενα), καλεντάρι, πρόοδο, οικονομικά, ρυθμίσεις, σκούρο θέμα, εισαγωγή/εξαγωγή JSON.
- **Μαθητής/τρια** — αποκτά λογαριασμό με δύο τρόπους:
  1. Ο καθηγητής: *Μαθητές → Προβολή → Λογαριασμός μαθητή* → email + κωδικός → «Δημιουργία λογαριασμού».
  2. Ο καθηγητής πατά «Σύνδεσμος πρόσκλησης» και στέλνει τον σύνδεσμο `https://…/?invite=ΚΩΔΙΚΟΣ` (ισχύει 14 ημέρες).
  Ο μαθητής βλέπει: τα δικά του μαθήματα (σημειώσεις μαθήματος, εργασίες, πληρωμές), πρόοδο, και το υλικό του καθηγητή.

## Υλικό (σημειώσεις & ασκήσεις)
*Υλικό μαθητών → Νέα σημείωση / άσκηση*: τίτλος, κείμενο, προθεσμία, έως 5 συνημμένα (5MB το καθένα).
Παραλήπτης: συγκεκριμένος μαθητής, **τάξη/επίπεδο** (ταιριάζει με το πεδίο «Τάξη/Επίπεδο» του μαθητή) ή όλοι.

## Τοπικά
```bash
npm install
DATABASE_URL=postgresql://... node server.js   # http://localhost:3000
node scripts/smoke.js http://localhost:3000    # API smoke test
```

## Deploy (Render + Neon)
`render.yaml` στη ρίζα. Web Service: build `npm ci --omit=dev`, start `node server.js`, health `/healthz`.
Env: `DATABASE_URL` (Neon), `NODE_ENV=production`, `ALLOW_SIGNUP=true`, `NODE_VERSION=20`.

## Ασφάλεια
Κωδικοί με scrypt, sessions σε HttpOnly cookie (Secure σε production), απομόνωση ανά καθηγητή στον server,
προστασία CSRF (header `X-App`), όριο αποτυχημένων συνδέσεων, τα συνημμένα κατεβαίνουν πάντα ως αρχεία.
`ALLOW_SIGNUP=false` κλείνει τις νέες εγγραφές καθηγητών (οι προσκλήσεις μαθητών συνεχίζουν να δουλεύουν).
